# AI 产品经理面试讲解提纲

## 30 秒版本

这是一个面向国内运动电商的中文 Agentic RAG 平台。我在开源技术基线之上完成了国产模型迁移、中文意图路由、CJK 混合检索、中文领域数据与评测集、多轮推荐偏差修复和成本评估。系统采用确定性路由加统一安全回答管线，能够在商品推荐、订单、投诉和政策场景中回答、拒答或转人工。

## 设计决策

1. 路由采用规则优先、小模型兜底，因为分类任务不值得默认调用大模型。
2. 各业务 lane 共用一个安全管线，避免订单隐私和 grounding 规则出现多套实现。
3. 语义问题走混合检索，关系问题走图谱，精确数字走受治理指标层。
4. 证据不足时拒答或进入人工队列，人工答案审核后再进入知识与评测闭环。
5. 模型和检索变更必须经过 Golden Set、RAGAS、消融和安全门禁，不自动上线。

## 需要主动说明的边界

- 数据为合成演示数据，当前成本是估算，不是生产账单。
- 中文路由集规模仍小，100% 不能外推到真实流量。
- Context Recall 偏低，是下一阶段应优先优化的指标。
- 项目基于开源架构改造，贡献重点是中文产品化与验证，而不是声称从零开发所有底层组件。
